# Быстрый запуск

## Linux

Распакуйте `AudioALL-linux-x86_64.tar.gz` и запустите:

```sh
./AudioALL/bin/AudioALL
```

Или из проекта: `./dist/linux/AudioALL/bin/AudioALL`.

Файлы сохраняются в `~/AudioALL/received`. Папку можно изменить кнопкой внизу окна; новый путь применяется к следующим сеансам приёма. Двойной щелчок открывает выбранный файл в системном приложении.

## Android

Установите `dist/AudioALL-android.apk` из файлового менеджера. Разрешите установку APK для этого файлового менеджера, если Android попросит. При нажатии «Включить приём» разрешите микрофон. Разрешения на интернет и полный доступ к хранилищу не требуются.

Кнопка выбора файла открывает системный менеджер документов. Принятые файлы хранятся внутри приложения. Кнопка «Принятые файлы» позволяет открыть файл, сохранить копию в выбранную папку или поделиться им. Удаление приложения удаляет внутренние файлы: нужные файлы сохраните отдельно.

## Первая проверка без звукового оборудования

1. Выберите «Текст» и напишите короткое сообщение.
2. Выберите «4FSK 600», один повтор.
3. Нажмите «Сохранить WAV» / «Сохранить сигнал в WAV».
4. На другом устройстве откройте этот WAV для приёма. Текст должен появиться после полного пакета.
5. Повторите с картинкой и Robot 36. Затем проверьте Robot 72, PD 50, PD 120 и Martin 1.

Для аудио/видео сначала попробуйте маленький файл. Передаётся оригинальный контейнер: полученный файл должен открываться тем же проигрывателем, что и исходный.

## Передача динамиком в микрофон

1. На приёмнике выберите вход и включите приём **до начала сигнала**.
2. На передатчике выберите выход, тип данных и протокол.
3. Начните с средней громкости. Уровень приёмника должен быть заметно выше тишины, но не приближаться к 0 dBFS: перегрузка искажает тоны.
4. Для помех выберите 4FSK 300 и 2–3 повтора. Для картинки Robot 36 быстрее, а PD 120 имеет большее разрешение.
5. Уберите обработку голоса, шумоподавление, эквалайзер и пространственные эффекты в настройках устройств. Приложение Android пытается отключить AEC/AGC/NS, но не все телефоны разрешают это.
6. Дождитесь последней строки / последнего пакета. Неполный цифровой файл не выдаётся за успешно принятый.

Если весь файл не восстановился, уменьшите громкость при перегрузке, поднесите устройства ближе или подключите звуковой кабель и повторите передачу. Новая передача имеет новый ID и принимается заново.

## Одновременный TX/RX

На одном устройстве можно сначала включить приём, а затем запустить передачу. Интерфейс и DSP выполняют эти операции в разных потоках. Это полезно для контроля собственной передачи, работы с независимыми входом/выходом и одновременного кодирования файла при приёме.

Для одновременного встречного обмена между двумя устройствами используйте раздельные входящие и исходящие звуковые каналы. При передаче двумя динамиками в одной комнате сигналы на одинаковых частотах мешают друг другу. Передавать несколько разных протоколов одним динамиком одновременно программа не предлагает.

## WAV

Сигнал экспортируется в WAV PCM16 mono 48 кГц. Для переноса сигнала используйте WAV/FLAC без потерь; MP3 может повредить цифровые пакеты. Для импорта поддерживается WAV PCM16 mono/stereo с частотой 8–192 кГц. Stereo сводится в mono; каналы в противофазе могут взаимно погаситься.
